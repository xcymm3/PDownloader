# 0.3.8 媒体预览调整与验证

## 行为

- 图片预览使用不透明黑底，移除底部按钮。长按已下载图片可分享原文件或通过系统文件选择器保存副本；网页资源图片可分享链接或下载当前图片。
- 图片拖动和速度跟踪使用屏幕坐标，避免图片自身平移抵消手指位移。慢划达到 24dp 或同方向快速轻划达到 8dp 即可切换；保留边界回弹、缩放和平移动作。
- 内置播放器左上角提供返回和标题，底部为上一个视频、播放/暂停、下一个视频、倍速和全屏切换。移除右上角重复的视频切换按钮。
- 倍速范围为 0.5～2 倍，切换视频沿用当前倍速。右侧锁定键禁用播放控件及画面拖动，锁定时返回键先解锁。
- 包含上一提交的画面拖动修复：拖动位移占画面宽度的比例对应视频总时长的相同比例，不再限制为每屏最多两分钟。
