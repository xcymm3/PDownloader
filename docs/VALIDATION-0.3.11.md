# 0.3.11 普通 AES-128 HLS 下载

## 行为

- 支持点播 HLS 的 `METHOD=AES-128`、`KEYFORMAT=identity`（省略时同样按 identity）、密钥格式版本 1，使用 AES-128 CBC 与标准填充解密。
- 支持显式 IV、按无符号 64 位媒体序号生成 IV、密钥轮换和 `METHOD=NONE` 切回未加密分片。初始化片段不消耗媒体序号；加密 `EXT-X-MAP` 要求显式 IV。
- 支持 TS、fMP4 初始化片段与字节范围下载。仅解密并校验传输长度、填充成功的分片会提交为完成文件；失败或中断的临时分片不会作为完成分片复用。
- 密钥通过既有 HTTP(S) 请求链路获取，沿用按域限定的认证、Cookie、重定向和目标地址检查。仅接受 16 字节密钥，按密钥声明缓存于任务内存，不保存密钥文件，离开下载流程时清空缓存数组。
- 已完成的明文分片可用于继续下载。下载结果按原有 HLS 流程播放、通知和导出 ZIP；离线清单不再保留远程密钥引用。没有新增“加密下载成功”或其他加解密专用界面文案，也没有新增 MP4 合并功能。
- SAMPLE-AES、其他非支持方法、非 identity 密钥格式及 DRM 继续使用原提示：`暂不支持加密 HLS 或 DRM 媒体`。
