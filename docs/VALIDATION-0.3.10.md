# 0.3.10 内置播放器手势

依据用户提供的 WDownloader 本地播放器手势说明独立实现。该手势层用于 PDownloader 内置播放器，覆盖已下载视频和内置播放器在线预览；网页自带播放器仍使用原来的全屏手势。

## 操作与计算

| 操作 | 功能 |
| --- | --- |
| 单指横滑 | 向右快进、向左快退 |
| 左半边竖滑 | 向上增加窗口亮度，向下减少 |
| 右半边竖滑 | 向上增加媒体音量，向下减少 |
| 左三分之一双击 | 快退 10 秒，连续点击可累计 |
| 右三分之一双击 | 快进 10 秒，连续点击可累计 |
| 中间双击 | 播放或暂停 |
| 单击 | 显示或隐藏播放控件 |

- 横滑先将像素换算成 dp，每 dp 对应 `总时长毫秒数 / 600`，限制在 100～1000ms。5 分钟视频横滑 100dp 调整约 50 秒；10 分钟及以上视频横滑 100dp 调整约 100 秒。
- 亮度每向上滑动 200dp 增加 1，音量每向上滑动 300dp 增加 1，均限制在 0～1。音量换算到设备实际档位，提示反映实际音量。
- 起始位移超过系统触摸阈值后按横纵位移选择模式，本轮固定模式。横滑起点距离左右边缘需至少约 10dp。按钮、顶部标题栏、可见底部控制条保留各自操作。
- 反向时以此前的手指位置和当前数值重设基准，首次反向移动立即生效，包括触及上下限后的反向微调。
- 横滑过程中持续更新时间提示，以最多每 100ms 一次向播放器提交定位请求，松手补交最后位置。开始定位时记录播放意图并暂停，结束后恢复原来的播放或暂停状态。
- 目标时间按播放范围钳制。计算模型支持额外起止边界；当前内置播放器使用媒体有效时长，尚无单独的片段播放区间设置。
- 双击累计使用 Android 双击时间窗口。同方向连续点击累计，换方向或超时重新计数。
- 亮度只修改当前窗口，初始跟随系统时读取系统亮度作为起点；音量通过 `AudioManager.STREAM_MUSIC` 调整并保留。亮度和音量提示在操作结束后淡出。
- 设置中“播放器手势”默认开启，关闭后停用上述自定义手势；锁定状态或播放器不可用时也会停用。多指、失去播放前台状态、切换视频、尺寸变化和离开窗口时清理手势与待执行定位。
- 新增普通权限 `MODIFY_AUDIO_SETTINGS`；没有申请修改系统全局亮度的权限。

## 验证（2026-11-13）

- `testDebugUnitTest`：28 项通过，其中新增 10 项手势计算测试，覆盖灵敏度、边界反向、亮度和音量、播放区间及双击累计。
- 独立 `pdownloader-ui-validation` 模拟器运行 `MediaUiTest`：5 项通过，包括拖动结束前的实际定位、播放/暂停恢复、切后台中断、窗口亮度、媒体音量、手势开关和锁定；图片及已有视频播放回归通过。
- 测试通过原生状态和绑定 API 执行，没有注入触摸、鼠标或键盘事件。实际手指操作的识别与手感仍需真机人工体验，逐帧画面刷新受视频关键帧和解码性能影响。
