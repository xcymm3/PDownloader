# 人工验收清单

本项目禁止通过桌面自动化操作界面。以下步骤由用户在设备上手动执行。

1. 启动：名称为 PDownloader，底部按顺序为“浏览 / 下载中 / 已下载”。首次打开为原生首页。
2. 地址栏：输入 `example.com` 后进入 HTTPS 页面；输入中文关键词后进入 Google 搜索；空输入和 `javascript:alert(1)` 不执行。
3. 导航：打开同一网站的多个页面，检查后退、前进、刷新、系统返回键；从网页退回首页，再返回应将应用移到后台。
4. 多标签：新建两个不同页面；切换后网址、页面及后退栈独立；关闭当前和后台标签；关闭最后一个标签后保留空白首页。
5. 标签回收：打开至少 6 个标签，再返回第一个，确认页面可以恢复或重新加载，应用不崩溃。
6. 收藏：收藏同一网址两次，只保留一条；从收藏打开；删除；重启后检查持久化。
7. 历史：成功打开网页后显示标题、网址及时间；重复网址合并；删除单条；清空时需要确认，清空后收藏仍保留。
8. 会话：关闭并重新启动应用，恢复普通标签网址、标题及选中的标签。页面会重新加载。
9. 视频：打开 debug 专用 `https://pdownloader.test/video`，播放后进入全屏。设备原先横屏时也应进入竖屏；系统工具栏隐藏；横向视频不应被强制拉伸；退出按钮和返回键均可恢复页面与原方向。
10. 视频生命周期：播放时切换后台、切换标签、进入下载页、退出全屏、反复进入全屏，检查无音频残留和黑屏。不同站点的视频控件都需要抽样验证。
11. 主题：系统浅色 / 深色分别启动及运行中切换；检查首页、地址栏、弹出菜单、收藏、历史、占位页文字可读。网站外观遵循其自身样式和内核能力。
12. 布局：窄屏、字体放大、横屏、键盘弹出、手势导航和三键导航下检查地址栏、按钮、列表及底部安全区域。
13. 网络：断网打开网址显示重试页；恢复网络后可重试；无效证书不会自动放行。
14. 下载入口：下载中与已下载为真实列表；往返切换时网页保留，正在下载的任务继续运行。

## 0.2.0 嗅探与下载验收

15. 从右上菜单进入“本地下载功能测试”，等待延后视频和跨源 iframe 出现；视频和图片悬浮按钮分别计数。拖动按钮后切换标签 / 改变窗口尺寸，按钮不超出网页区域。
16. 视频资源面板：同一 video 的多个 source 作为一个内容组；HLS 主清单的两个版本属于一组；同标题不同视频仍独立。未知大小显示未知。
17. 保持面板打开，等待新增候选，确认不跳回顶部、不重排已操作的格子，也不把新内容加入当前选择。单个视频只选一个清晰度；新版本不覆盖手选版本。
18. 重命名只影响下载名称，网页标题不改变；禁用的加密 / 独立音轨版本不能被加入下载。下载按钮数量与实际选中项一致。
19. 图片三列网格，逐个选择与全选 / 清空正确；进入预览，左右切换、当前勾选、已选数量和下载按钮保持一致。返回面板不丢选择。
20. 普通视频选择后创建真实任务，重复提交同一任务不重复创建；下载后可播放。图片下载后可查看；大图应采样而非一次解码全部原图。
21. 下载中查看状态、进度和原因；大小未知不显示假百分比；HLS 显示分片进度及整理阶段。测试单项及全部暂停 / 继续。
22. 下载时关闭浏览页、切换应用、重建界面；任务应仍可跟踪。杀死应用进程后重新打开，未完成任务显示暂停并可继续，不能伪装成正在传输。
23. 中断网络后查看有限重试与错误；恢复后继续。链接过期或拒绝访问时能打开来源网页重新检测，不将新地址直接追加到旧文件。
24. HLS 离线：完成点播下载，断网后从“已下载”播放；播放不依赖原始站点或临时签名。TS 与带初始化片段 / 字节范围的 fMP4 需分别检查。
25. 已下载支持全部 / 视频 / 图片分类、搜索、排序、原网页、显示名修改；在线播放不会被计为已下载。
26. 普通视频分享 / 导出是原文件；HLS 是 ZIP 资源包，提示不是 MP4；ZIP 中应只有本地清单和分片，不含 Cookie / Authorization。解压后可由支持本地 HLS 的播放器读取。
27. 仅删完成任务的下载记录后，文件和“已下载”中的本地媒体入口保留；“同时删文件”才清理媒体。未完成任务取消 / 删除会清理临时文件，且不会被晚到的回调重新标成完成。
28. 内置播放器使用播放 / 暂停、拖动进度、全屏与返回。全屏默认竖屏，系统栏和标题栏隐藏；返回优先退出全屏；切到后台后停止播放音频。
29. 在需要登录的自有测试站点登录后下载，检查 Cookie/Referer/UA 与网页一致；不要用含敏感令牌的网址截图或日志作为公开反馈。
30. 浅色 / 深色、320dp 窄屏、大字体和横屏下检查资源卡片、固定下载按钮、图片预览、下载列表、播放器与系统安全区域。

YouTube、直播、DRM、加密 HLS、独立音轨合并、所有站点通用适配、保险箱、投屏和云服务不作为已完成项。其他交接场景的自动化 / 人工验证范围见 `MEDIA_DESIGN.md` 及验证记录。

自动化验证范围及结果记录在 `docs/VALIDATION.md`。没有运行过的设备检查不得视为已通过。
