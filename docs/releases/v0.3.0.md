PDownloader 0.3.0 将标签页与媒体库改为两列卡片，整理浏览器菜单，并改善视频播放交互。

- 标签页显示窗口预览、当前项高亮，支持新建、切换和关闭。
- 收藏夹改为独立页面，支持搜索、打开、复制与删除。
- 下载中 / 已下载保留独立页面缓存，去掉切换后的延迟刷新。
- 网页操作移动到右上菜单顶栏：后退、前进、收藏、分享、刷新；菜单项目带左侧图标。
- 网页和内置播放器全屏强制横屏；内置播放器支持在画面上横向滑动调节进度。
- 已下载仅视频 / 图片，默认视频，两列卡片显示封面、名称和时长；长按可分享、导出、重命名和删除。

下载附件中的 **PDownloader-0.3.0.apk** 安装，最低 Android 8.0。SHA256SUMS.txt 用于校验下载文件。

这是使用专用签名的 Release 包，不包含调试测试页与媒体。之前安装过调试版的用户，首次转为正式版需要先备份下载文件并卸载调试版（签名不同）；后续正式版保持同一签名，可覆盖升级。

验证：12 项 JVM 测试、26 项安卓集成测试通过；标签预览修正后追加 4 项界面回归通过，签名校验和独立模拟器安装 / 冷启动检查通过。手势手感仍需真实设备体验。网站全屏手势限可访问且时长可用的 HTML 视频；跨源封装播放器受站点隔离限制。

源代码与完整验证记录见仓库 docs/VALIDATION-0.3.0.md。
