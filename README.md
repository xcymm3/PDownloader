# PDownloader

PDownloader 是一款免费开源的安卓浏览器，支持识别网页中的图片和视频、管理下载任务，以及离线播放。浏览网页时，可以直接查看本页找到的资源，选择需要的内容下载，再到应用里查看或播放。

[下载最新正式 APK](https://github.com/xcymm3/PDownloader/releases/latest) · [反馈问题](https://github.com/xcymm3/PDownloader/issues) · [MIT 许可证](LICENSE)

支持 Android 8.0 及以上版本。

## 下载安装

打开上方下载链接，在发布页的 Assets 中选择 `PDownloader-版本号.apk`。下载完成后打开安装包，按 Android 的提示允许当前来源安装应用。

更新时直接安装新版正式 APK。正常覆盖升级会保留下载记录、浏览历史和收藏，请勿先卸载旧版。应用也支持在设置中检查更新，自动下载安装包后，由你在系统安装页面确认。

## 可以用它做什么

### 浏览网页

- 首页有百度、Google、哔哩哔哩、YouTube、X 和 Instagram 入口，也可以直接输入网址或搜索词。Google 入口和默认搜索使用香港站 `www.google.com.hk`。
- 地址栏会从本机历史、收藏和已打开标签中提供联想，最多显示 5 项，列表不显示滚动条，不联网获取搜索建议。
- 多标签以两列卡片展示，可以预览、切换和关闭。
- 收藏夹和历史记录各有独立页面，支持搜索，按日期分组并显示网站图标。删除前会请你确认。
- 支持网页上传图片和附件。HTTPS 网站需要使用摄像头、麦克风或位置时，可以按提示授权，也可以在设置中撤销站点权限、清除 Cookie。

界面可以跟随系统切换浅色、深色，也可以在设置里自行选择。底部三个图标分别对应浏览、下载中和已下载，选中的页面会高亮。

### 下载网页资源

浏览时，右下角的资源图标会显示已发现的资源数量。打开面板后，可以预览图片、选择视频版本、修改名称，再下载选中的内容。

同时下载数量可设为 1 到 8 项，默认 8 项。下载任务支持暂停和继续；失败时可根据提示重试、回原网页登录或重新检测资源。应用会保存任务状态，进程被系统关闭后，可以重新打开并手动继续。

已下载的文件按视频、图片和其他分类。PDF、ZIP、音频等普通文件归入“其他”，可交给手机上的对应应用打开。文件卡片支持长按分享、导出、重命名或删除。

也可以从其他应用把网页链接分享到 PDownloader。对于 B 站视频页和可识别的 b23.tv 短链接，应用会尝试识别资源；未识别到、需要登录或请求超时时，可以进入浏览器继续操作。

### 播放视频、查看图片

内置播放器会记住每条视频的播放位置，支持切换上一个或下一个视频、0.5 到 2 倍速，以及锁定控件防止误触。

拖动进度条或直接在视频画面上横向滑动，都可以调整播放位置。画面拖动按视频总时长的比例计算，中央会显示目标时间和进度。进入全屏后自动横屏，即使手机锁定竖屏也会切换，退出后恢复原方向。

图片采用黑底全屏预览，左右轻划切换，双指或双击缩放，轻点关闭。长按已下载图片可以分享原图或另存副本；网页资源图片可分享链接或下载当前图片。

## 第一次下载

1. 打开允许下载的网页。如果需要登录，先在网页中登录；下载视频时，先播放视频，让页面加载媒体资源。
2. 点击右下角的资源图标，选择图片或视频版本，再点击面板底部的下载图标。
3. 点击底部中间的圆环下载图标，查看进度或暂停任务。
4. 下载完成后，点击底部右侧的勾选文件夹，查看图片、播放视频或打开其他文件。

资源面板没有找到内容时，可以尝试播放视频后重新检测。能否识别和下载，取决于网页提供的资源形式。

## 文件保存在哪里

新任务默认在下载完成后保存到公共目录 `Download/PDownloader`。普通视频、图片及其他文件会保留原文件形式，可以从系统文件管理器中查找，并交给对应应用打开。

设置里可以改用应用私有目录。此前已保存在私有目录的文件，可到“已下载”中长按导出。

HLS 视频保存为 ZIP 离线资源包，应用内保留播放所需的分片。导出后可解压，通过 `offline.m3u8` 播放，不能把这个 ZIP 当作单个 MP4 使用。

删除下载记录会保留已完成的文件及本地媒体库入口；选择“同时删文件”才会清理完成媒体。删除未完成任务会清理它的临时文件。

## 更新与数据

应用打开时会检查 GitHub 正式 Release，自动检查间隔为 24 小时。也可以随时到“设置 → 检查更新”手动检查，选择立即更新或稍后更新。

如果发布页能打开，检查更新却提示 GitHub 暂时无法提供版本信息，可能是当前网络出口触发了 GitHub API 限流。可以稍后重试、切换网络，或从[发布页](https://github.com/xcymm3/PDownloader/releases/latest)下载 APK 覆盖安装。

浏览历史和收藏仅保存在应用私有目录，不上传到服务器，Android 自动备份默认关闭。清空历史不会删除收藏。卸载应用会清除应用私有数据，更新时请使用同一签名的正式安装包覆盖安装。

## 使用范围

目前支持普通 HTTP(S) 文件下载，以及未加密、已结束的点播 HLS。以下功能尚不支持：

- YouTube 视频下载、直播录制、加密 HLS 和 DRM 内容下载。
- 分离音轨与视频合并、将 HLS 重封装为单个 MP4。
- 无痕模式、密码同步和广告过滤。

网站入口可用不代表该网站的视频一定能下载。部分网页全屏播放器受跨域限制，无法使用画面拖动定位。网站兼容性、视频解码和网络可达性也会受到系统 WebView、手机及所在网络的影响。

下载通过前台服务运行。Android 对后台任务和服务运行时间有系统限制，任务可能转为暂停，需要你再次点击继续。

## 浏览与权限

PDownloader 启用 Safe Browsing，不放行证书错误，禁止 HTTPS 网页加载 HTTP 混合资源。访问普通 HTTP 网站时，连接本身不受 TLS 加密保护。

网页上传使用 Android 系统文件选择器。站点权限和 Cookie 可以在“设置 → 隐私和网站”中管理。请保持手机的系统 WebView 更新。

## 反馈问题

请到 [GitHub Issues](https://github.com/xcymm3/PDownloader/issues) 提交问题，附上手机型号、Android 版本、PDownloader 版本，以及能重现问题的操作步骤。截图或报错文字也有助于排查。

反馈网站问题时，可以提供公开可访问的页面地址。请勿附上账号密码、Cookie、令牌或带有个人凭据的完整下载链接。
