# PDownloader

使用 Kotlin + Android WebView 开发的原生安卓浏览器，当前源码版本 0.3.7，最低支持 Android 8.0（API 26）。依据用户提供的《WDownloader-资源嗅探与界面重建交接》独立实现媒体发现、资源选择、下载与播放；使用自己的名称、图标和代码，不依赖原应用的解析服务器。红色主操作、主题可选跟随系统、浅色或深色。

图标采用已确认的黑底、红色空心方框与白色 P 下载箭头，提供矢量资源和自适应桌面图标。[图标设计稿](docs/branding/icon-approved.png)

[下载最新正式 APK](https://github.com/xcymm3/PDownloader/releases/latest) · [0.3.0 验证与截图](docs/VALIDATION-0.3.0.md)

## 当前功能

- 应用打开时检查 GitHub 正式 Release，也可以在「设置 → 检查更新」手动检查。选择立即更新后自动下载并校验 APK，接着由 Android 确认安装。选择稍后更新后，24 小时后再自动提醒。
- 首页提供直接输入的搜索框与百度、Google、哔哩哔哩、YouTube、X、Instagram 六个常用网站入口，网站图标本地绘制；进入网页后显示地址栏。Google 入口和默认搜索使用香港站 `www.google.com.hk`，网络可达性取决于所在环境。
- 首页搜索框和地址栏从本机历史、收藏和已打开标签提供联想，匹配标签时可直接切换过去。联想过程不联网。
- 网页上传用 Android 系统选择器选取图片和附件。HTTPS 网站可请求摄像头、麦克风或位置权限，可在「设置 → 隐私和网站」撤销授权或清除网站 Cookie。
- 多标签：独立的两列预览卡片，当前标签高亮，可新建、切换、逐个关闭；缩略图仅在内存保留。最多 32 个标签，同时最多保留 4 个活跃 WebView。回收的标签会在进程内尽量恢复导航状态。
- 收藏夹为独立页面，可搜索标题或网址，按天分组并显示站点图标，点击打开，删除需确认，返回保留原标签；按网址去重、本地保存。
- 历史记录为独立页面，保留底部导航；可搜索标题或网址，按天分组并显示站点图标和访问时间。点击记录打开网页，右侧删除按钮需确认。清空历史仍保留收藏。按网址合并最近访问记录，最多 2000 条，重建后保留历史页和搜索条件。
- 视频全屏：网页与内置播放器均主动请求横屏，即使系统关闭自动旋转；退出后恢复方向。内置播放器可在画面上横向拖动定位，松手跳转，控制条仍可独立操作；网页全屏对可访问、具有已知时长的 HTML video 提供同类操作，跨源播放器受网页隔离限制。
- 右上角菜单顶部提供前进 / 收藏 / 刷新三个图标，分享网页位于下方列表。界面重建时恢复有大小上限的网页导航状态，新窗口可返回来源标签。
- 普通标签网址和标题在重启后恢复；重启不会恢复播放进度、表单或完整后退栈。
- 底部导航仅显示浏览、下载中、已下载三个图标，当前项高亮。
- 通用资源发现：video/currentSrc/source、图片实际地址、延后插入内容、开放 Shadow DOM、可归属的 ServiceWorker 请求、受限的跨源 iframe 辅助探测；每个标签与导航代次隔离。
- 播放时才出现的无后缀地址会通过当前文档、iframe 或性能条目确认归属，再限量验证 HLS 内容。页面只提供 blob 地址时，仍可用它作为寻找底层请求的线索。
- 右下统一资源图标：徽标显示去重资源数量，可拖动并保存相对位置；长按查看视频 / 图片数量说明。
- 紧凑资源面板：视频分组与版本选择；重命名、预览、重新检测、全选 / 取消使用图标，图片角标为透明点击区域上的方形勾选框；底部下载图标加数量。
- 图片共用半透明全屏预览：轻点图片或遮罩关闭，关闭图标、左右切换、双指缩放和双击缩放；资源选择与预览同步，已下载图片可在预览中分享和导出。
- 普通媒体流式下载、队列去重、暂停 / 继续、校验 ETag/Last-Modified 的断点续传；临时网络错误最多重试两次。
- 下载失败卡片按原因提供继续下载、回原页登录或重新检测。选中替换资源后沿用原任务；地址变化时从头下载，旧分片不会混入。
- 未加密、已结束的点播 HLS：主清单版本、TS / fMP4、初始化片段、字节范围和 discontinuity；已完成分片可复用。保存为离线资源包，不拼接成伪 MP4。
- 在「设置」或「下载中」可选同时下载 1 到 8 项，默认 8 项。设置会保留，调低上限时等待当前任务自然释放名额。
- 前台下载服务与通知进度、暂停全部；任务持久化，浏览页销毁后可继续。进程或系统服务停止后保留为暂停，用户再次点击继续。
- 已下载按视频 / 图片 / 其他筛选，默认视频。PDF、ZIP、音频等普通 HTTP(S) 下载归入「其他」，可交给系统应用打开。卡片支持长按分享 / 导出 / 重命名 / 删除。下载中与已下载保留独立视图和数据缓存，切换时显示对应标题与缓存内容。
- 视频使用明确的 48dp 进度触摸区域，也可在画面上横向拖动，中央显示目标时间、总时长和小进度条。内置播放器保存每条视频的位置，已下载视频可通过右上角按钮切换上一条和下一条。
- 普通文件分享 / 导出为原文件；HLS 分享 / 导出为 ZIP，解压后通过 offline.m3u8 播放，**不是单个 MP4**。
- 支持 Android 分享网页链接。B 站视频页和可识别的 b23.tv 短链接优先使用站点公开网页接口获取单文件版本和封面，可取消识别或打开原网页。未命中、需要登录或超时会进入内置浏览器。

## 快速体验下载

1. 安装 APK，打开允许下载的网页并播放视频。
2. 等待媒体资源被发现，页面必要时需先登录。
3. 点击右下方叠层形状的资源图标，选择视频版本或图片后点击下载图标。
4. 到“下载中”查看进度，到“已下载”播放、查看、分享或导出。

开发专用的本地测试页和四秒钟 AVC/AAC 媒体不依赖外部网络，服务只在 Debug 包监听设备回环地址。测试入口已移出菜单；开发者可使用 `adb shell am start -n com.pdownloader.browser/.MainActivity --ez local_download_fixture true` 打开。Release 不包含测试服务器或测试媒体，忽略该参数。

## 构建与安装

需要 JDK 17 或 21、Android SDK Platform 36 和网络连接。项目内含 Gradle Wrapper，无需全局安装 Gradle。

1. 安装 SDK Platform 36，并准备 JDK 17 或 21。Android Studio 可选，也可直接使用命令行工具链。
2. 在本机 `local.properties` 中填写 SDK 路径；Windows 示例为 `sdk.dir=C\:/Android/Sdk`（使用正斜杠，并转义盘符冒号）。
3. 执行：

```powershell
$env:JAVA_HOME = '你的 JDK 17 或 21 路径'
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

正式发布签名配置说明见 [RELEASING.md](docs/RELEASING.md)。`signing.properties` 与私钥不进入 Git。

生成 APK：`app/build/outputs/apk/debug/app-debug.apk`。这是调试签名，发布版本需要自行配置签名；不要将密钥提交到仓库。

JVM 测试覆盖网址解析、清单解析、签名参数保留、文件命名、私网地址拒绝、跨源重定向的 Cookie / Authorization 隔离。Android 集成测试使用独立本地服务器和真实生成的视频，覆盖浏览回归、DOM 与 iframe 探测、文件字节一致性、暂停续传、取消、HLS 分片失败恢复、离线播放器准备及服务生命周期。具体执行结果见 [docs/VALIDATION.md](docs/VALIDATION.md)。

```powershell
# 连接一台专门用于测试的设备或模拟器后执行；数据库测试会清除测试安装中的收藏和历史。
.\gradlew.bat :app:connectedDebugAndroidTest
```

人工验收步骤见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。旧版全屏测试地址 `https://pdownloader.test/video` 仍保留；新的完整下载测试可通过上述 Debug 专用命令打开本地测试页。测试媒体可通过 `python tools/generate-fixtures.py` 重建，需要 `imageio-ffmpeg`。

## 项目结构

```text
app/src/main/java/com/pdownloader/browser/
  MainActivity.kt      浏览器页面、标签、菜单、会话恢复与全屏生命周期
  BrowserUi.kt         原生界面组件与图标
  BrowserStore.kt      SQLite 收藏与历史仓库
  AddressResolver.kt   网址校验与搜索词解析
  MediaSheet.kt        视频 / 图片选择、稳定选择与图片预览
  DownloadsView.kt     下载列表、过滤、排序与任务动作
  PlayerActivity.kt    Media3 在线与离线播放器
  ImageGalleryDialog.kt 统一图片预览、透明遮罩与缩放 / 切换
  media/               会话探测、独立脚本、HLS 解析、请求上下文与受限 HTTP
  download/            SQLite 任务与本地媒体库、执行引擎、前台服务
app/src/main/res/values[-night]/  跟随系统的颜色与主题
app/src/test/                    纯 JVM 测试
app/src/androidTest/             Android 数据库集成测试
```

当前使用 Android 原生 View，下载传输由前台服务和有上限的并发工作池持有，列表与浏览记录查询放在 IO 执行器。应用启动会同步执行少量数据库初始化与中断任务恢复。

范围和默认规则见 [docs/MEDIA_DESIGN.md](docs/MEDIA_DESIGN.md)。本版不支持 YouTube 下载、直播录制、加密 HLS、DRM、独立音轨合并、MP4 重封装、云盘 / 会员 / 广告业务。无痕、密码同步、搜索建议编辑页、广告过滤仍未实现。站点可用性取决于其接口响应、系统 WebView 和设备解码器。

## 浏览安全设置

不暴露 JavaScript 原生桥；禁止网页直接访问本地 file/content 资源；启用 Safe Browsing；不放行证书错误；禁止 HTTPS 页面加载 HTTP 混合资源。为支持用户主动打开普通 HTTP 网站，应用允许明文 HTTP；HTTP 流量不受 TLS 保护。收藏和历史仅保存在应用私有目录，不上传到服务器，关闭 Android 自动备份。

下载网络请求只允许 HTTP(S)，拒绝解析为本机、内网等地址的目标；Debug 仅为本地测试放行回环地址和模拟器宿主地址。每一跳重定向重新取目标 Cookie；Authorization 绑定观察到的源，媒体版本分别保留请求上下文。不将 Cookie、令牌或完整签名地址输出到应用日志，不把凭据加入导出的资源包。

新任务默认在完成后写入公共 `Download/PDownloader`，也可在设置中选应用私有目录。普通媒体在公共目录保存为原文件，HLS 保存为 ZIP 离线包，应用内保留播放所需分片。此前存于私有目录的文件可继续在已下载中长按导出。设置还提供下载完成通知和按流量计费网络提醒。仅删下载记录会保留已下载文件及本地媒体库入口；未完成任务删除时清理临时文件。“同时删文件”才清理完成媒体。Android 15 的 dataSync 前台服务存在系统时限，超时会转为暂停；不承诺无限后台运行。

WebView 内核由设备提供，请保持其更新。外部应用链接必须由用户触发并经确认后打开。真实视频渲染、手势、网站登录和主题布局仍需人工验收。
